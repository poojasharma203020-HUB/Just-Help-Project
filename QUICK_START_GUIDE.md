# 🚀 QUICK START GUIDE - 5 Minutes Setup\n\n## ⚡ In 5 Minutes, You'll Have Everything Running!\n\n---\n\n## Step 1: Clone & Setup (2 minutes)\n\n```bash\n# Clone repository\ngit clone https://github.com/poojasharma203020-HUB/Just-Help-Project.git\ncd Just-Help-Project\n\n# Create environment files\ncp apps/mobile/.env.example apps/mobile/.env\ncp apps/web/.env.example apps/web/.env\ncp apps/mobile/env/dev.json.example apps/mobile/env/dev.json\n```\n\n---\n\n## Step 2: Fill Environment Variables (1 minute)\n\n### Get Supabase Credentials:\n1. Go to [supabase.com](https://supabase.com)\n2. Create free project\n3. Go to Settings > API\n4. Copy \"Project URL\" and \"anon public key\"\n\n### Edit apps/web/.env\n```\nVITE_SUPABASE_URL=https://your-project.supabase.co\nVITE_SUPABASE_ANON_KEY=eyJhbGciOiJIUzI1NiIsInR5c...\n```\n\n### Edit apps/mobile/env/dev.json\n```json\n{\n  \"SUPABASE_URL\": \"https://your-project.supabase.co\",\n  \"SUPABASE_ANON_KEY\": \"eyJhbGciOiJIUzI1NiIsInR5c...\",\n  \"FIREBASE_PROJECT_ID\": \"your-project-id\",\n  \"API_ENDPOINT\": \"http://localhost:3000\"\n}\n```\n\n---\n\n## Step 3: Setup Database (1 minute)\n\n```bash\n# Install Supabase CLI\nnpm install -g supabase\n\n# Navigate to web directory\ncd apps/web\n\n# Link to your Supabase project\nsupabase link --project-ref YOUR_PROJECT_REF\n\n# Apply all migrations\nsupabase db push\n\n# Verify\nsupabase db pull\n```\n\n**Done!** Your database is ready with 49 tables, all migrations, and security policies.\n\n---\n\n## Step 4: Start Development (1 minute)\n\n### Option A: Run Web Admin Panel\n\n```bash\ncd apps/web\nnpm install\nnpm run dev\n\n# Open http://localhost:3000\n# Login with any Supabase user\n```\n\n### Option B: Run Flutter Mobile App\n\n```bash\ncd apps/mobile\nflutter pub get\ndart run build_runner build --delete-conflicting-outputs\nflutter run --dart-define-from-file=env/dev.json\n\n# App runs on device/emulator\n```\n\n---\n\n## ✅ That's It! You're Running!\n\n### What You Now Have:\n- ✅ Web Admin Panel (28 pages)\n- ✅ Flutter Mobile App (90 screens)\n- ✅ Supabase Backend (49 tables, RLS security)\n- ✅ Real-time database\n- ✅ User authentication\n- ✅ Error handling\n- ✅ CI/CD pipelines\n\n---\n\n## 🔥 Production Deployment (10 minutes)\n\n### Build for Production\n\n```bash\n# Android APK\ncd apps/mobile\nflutter build apk --release --dart-define-from-file=env/prod.json\n# Output: build/app/outputs/apk/release/app-release.apk\n\n# iOS\nflutter build ios --release --dart-define-from-file=env/prod.json\n\n# Web\ncd apps/web\nnpm run build\n# Output: dist/ folder\n```\n\n### Deploy Web (Free Vercel)\n\n```bash\n# Install Vercel CLI\nnpm install -g vercel\n\n# Deploy\ncd apps/web\nvercel --prod\n```\n\n### Deploy Android (Google Play)\n\n```bash\n# Create account at play.google.com\n# Upload build/app/outputs/apk/release/app-release.apk\n# Wait for review (24-48 hours)\n```\n\n### Deploy iOS (App Store)\n\n```bash\n# Create account at developer.apple.com\n# Use Xcode to archive and upload to App Store Connect\n# Wait for review (24-48 hours)\n```\n\n---\n\n## 🆘 Common Issues\n\n### Issue: `flutter: command not found`\n```bash\n# Install Flutter\nchoco install flutter  # Windows\nbrew install flutter   # Mac\nsudo apt install flutter-sdk  # Linux\n```\n\n### Issue: `Node not found`\n```bash\n# Install Node.js\nchoco install nodejs   # Windows\nbrew install node      # Mac\nsudo apt install nodejs  # Linux\n```\n\n### Issue: `supabase: command not found`\n```bash\nnpm install -g supabase\n```\n\n### Issue: Database migrations fail\n```bash\n# Make sure you linked correctly\nsupabase link --project-ref YOUR_PROJECT_REF\n\n# Check project URL\nsupabase projects list\n```\n\n---\n\n## 📱 Test Features\n\n### Sign Up\n1.
